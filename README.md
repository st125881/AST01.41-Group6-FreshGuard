# FreshGuard: Design, Implementation, and Evaluation of a Low-Cost Edge-Cloud IoT System for Sustainable Cold Storage Monitoring

**Course:** AST01.41  
**Group:** Group 6  

## Live Dashboards & Services
* **Node-Red:** [https://freshguardnr.iotcloud-lab.com/](https://freshguardnr.iotcloud-lab.com/)
* **Garfanar:** [http://freshguardgf.iotcloud-lab.com/](http://freshguardgf.iotcloud-lab.com/)

## Repository Contents
* `Group6_FreshGuard_Arduino.ino` — Edge microcontroller firmware for sensor data acquisition and transmission.
* `Group6_FreshGuard_Nod-Red.json` — Node-Red flow configuration for edge-cloud data routing and processing.
* `Group6_FreshGuard_Garfanar.json` — Garfanar dashboard configuration for cold storage monitoring and visualization.
